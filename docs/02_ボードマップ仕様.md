# 02. ボードマップ仕様

## マップ構造

### 基本設計

- マップはボードゲーム型の**ループ構造**（周回型）
- 分岐（分かれ道）が存在する
- マップデータは JSON で外部定義し、差し替え可能

### マスの数（デフォルトマップ）

- メインルート: 32マス（8×8 の外周）
- 分岐ルート: 8マス（ショートカットまたは迂回路）
- 合計: 約40マス

### マップデータ構造

```json
{
  "map_name": "デフォルトマップ",
  "tiles": [
    {
      "id": 0,
      "type": "normal",
      "name": "空き地A",
      "land_price": 200,
      "next": [1],
      "position": {"x": 0, "y": 0}
    },
    {
      "id": 1,
      "type": "card_shop",
      "name": "カード売り場",
      "next": [2],
      "position": {"x": 1, "y": 0}
    },
    {
      "id": 5,
      "type": "normal",
      "name": "分岐点",
      "land_price": 300,
      "next": [6, 20],
      "position": {"x": 5, "y": 0}
    }
  ]
}
```

### マスの描画

- 各マスは 16×16 ピクセルのタイルで描画
- マス間は線で接続して経路を示す
- プレイヤーのコマは 8×8 ピクセルのスプライトで表示
- 1マスに最大4人のプレイヤーが重なれる（位置をずらして表示）

## マスの種類

### 1. 通常マス（normal）

- 土地があり、会社を建設できるマス
- 各マスに**地価**が設定されている
- 土地の所有者と会社のオーナーは別プレイヤーでも可

| 属性 | 説明 |
|---|---|
| `land_price` | 地価（購入価格と同額） |
| `owner_id` | 土地の所有者（null = 空き地） |
| `company` | 建設された会社情報（null = 未建設） |

### 2. カード売り場（card_shop）

- カードの売買ができるマス
- 販売カードは毎回ランダムに決定される
- 購入価格は各カードの定価
- 売却価格は定価の 1/5

### 3. プラスマス（plus）

- 止まるとお金がもらえるマス
- 金額: 100〜500$（マスごとに固定）

### 4. マイナスマス（minus）

- 止まるとお金を失うマス
- 金額: 100〜300$（マスごとに固定）

### 5. カードマス（card）

- 止まるとカードが1枚もらえるマス
- もらえるカードはランダムに決定
- 手持ちカードが上限（7枚）の場合はもらえない

## 分岐の処理

1. プレイヤーが分岐マスに到達した場合、進む方向を選択する
2. サイコロの残り歩数分、選択した方向に進む
3. 分岐選択後「止まりますか？」の確認が表示される
   - 「はい」→ そのマスに止まり、マスの効果を処理
   - 「いいえ」→ サイコロを振った直後の状態に戻り、別の方向を選択可能

## 土地と地価

### 地価の初期値

各通常マスに個別設定（100〜500$ の範囲、マップデータで定義）

### 地価の変動

- イベント「地価上昇」: ランダムなマスの地価が 30% 上昇
- イベント「地価下落」: ランダムなマスの地価が 20% 下落

### 土地使用料

- 計算式: `土地使用料 = 地価 × 20%`
- 他プレイヤーの土地に建設された自社の会社から、土地の地主に毎偶数ターンに支払われる
