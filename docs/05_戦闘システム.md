# 05. 戦闘システム

## 戦闘の発生条件

他プレイヤーの会社があるマスに止まった場合、**戦闘**が発生する。

- 攻撃側: そのマスに止まったプレイヤー
- 防御側: そのマスの会社のオーナー
- 使用する会社: 各プレイヤーが所有する全会社のパラメータを合算して戦う

## 戦闘パラメータと会社パラメータの対応

| 戦闘パラメータ | 対応する会社パラメータ | 計算方法 |
|---|---|---|
| HP（体力） | 社員数 | 所有全会社の社員数合計 |
| 攻撃力 | 社員数 + 会社評価額 | `社員数合計 + 会社評価額合計 / 10` |
| 防御力 | 能力 | 所有全会社の能力の平均値 |
| すばやさ | 知名度 | 所有全会社の知名度の平均値 |

## 行動順の決定

- 毎戦闘ターンごとに、各プレイヤーの**すばやさ**をもとにランダムで行動順を決定
- すばやさが高いほど先手を取りやすい
- 判定: `random(0, 100) < すばやさ` で先手判定

## 戦闘コマンド

各戦闘ターンに1つのコマンドを選択：

### 1. 攻撃

通常攻撃を行う。一撃で勝負が決まる可能性がある。

**ダメージ計算式:**

```
ダメージ = (攻撃力 × すばやさ / 100) - (相手の防御力 × 相手のすばやさ / 100)
```

- ダメージが0以下の場合、最低1ダメージ
- ダメージはランダム補正あり: ±20%
- 相手のHPからダメージ分を減算

### 2. 防御

防御に専念する。

- そのターン限り、**防御力が5倍**になる
- 攻撃は行わない

### 3. カード

手持ちの戦闘用カードを1枚使用する。

- 使用可能なカードは「戦闘時使用」に分類されるもののみ
- 1戦闘ターンに1枚使用可能

### 4. 逃げる

戦闘から離脱を試みる。

**逃走成功率:**

```
逃走成功率(%) = (能力 + すばやさ) / 300 × 100
```

- 成功した場合、戦闘終了
- 逃走したプレイヤーは、相手に対して一定額のペナルティ（所持金の5%）を支払う
- 失敗した場合、そのターンは何もできず相手の攻撃を受ける

## 戦闘の決着

### 勝利条件

- 相手のHPを0以下にしたプレイヤーが勝利

### 勝利報酬

- 敗北したプレイヤーの所有する会社のうち、**戦闘が発生したマスの会社**を獲得する

### 3〜4人対戦時の戦闘

- 同じマスに複数プレイヤーがいる場合、到着したプレイヤーとマスの会社オーナーの1対1で戦闘
- 3〜4人のプレイヤーが同時にいる場合の戦闘ルールについては要確認（→ Issue参照）

## 戦闘用カードの効果

| カード | 効果 | 持続 |
|---|---|---|
| 契約社員カード | 攻撃力が1.5倍になる | 1戦闘ターン |
| 社員教育カード | 防御力が2倍になる | 2戦闘ターン |
| TV CMカード | すばやさが2倍になる | 2戦闘ターン |
| ビル補修カード | HPが全HPの1/3回復 | 即時 |
| 社員引き抜きカード | 相手の攻撃力が0.7倍 | 戦闘終了まで |
| 比較CMカード | 相手のすばやさが0.7倍 | 戦闘終了まで |
