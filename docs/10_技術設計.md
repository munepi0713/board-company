## アーキテクチャ概要

### UI / ロジック 疎結合設計

本プロジェクトの最大の設計方針は、**ゲームロジック（`core/`）と描画（`views/`）の完全分離**である。

```
┌─────────────────────────────────────────────────┐
│                   scenes/                       │
│  （シーンがロジックとビューを組み合わせる）       │
│                                                 │
│   ┌──────────────┐       ┌──────────────┐       │
│   │  core/       │       │  views/      │       │
│   │  ゲームロジック│◄─────│  描画層      │       │
│   │              │       │              │       │
│   │ - 状態管理   │       │ - Pyxel描画  │       │
│   │ - ルール判定 │       │ - 座標変換   │       │
│   │ - AI        │       │ - アニメ     │       │
│   └──────────────┘       └──────────────┘       │
│         ▲                       ▲               │
│         │                       │               │
│    Pyxel非依存              Pyxel依存           │
│    テスト容易               差し替え可能         │
└─────────────────────────────────────────────────┘
```

**依存方向のルール**:

- `core/` は `views/` や `ui/` を **一切 import しない**
- `views/` は `core/` のデータモデルを **読み取る（Read）** のみ
- `scenes/` が `core/` と `views/` を組み合わせてゲームを構成する
- `core/` は Pyxel モジュールを **import しない**（純粋な Python ロジック）

この設計により、以下が可能となる：

| メリット | 詳細 |
|---|---|
| **ビューの差し替え** | トップビュー → アイソメトリックなど、`views/` 配下のモジュールを切り替えるだけでゲーム表現を変更可能 |
| **ロジックの単体テスト** | `core/` は Pyxel に依存しないため、`pytest` で直接テスト可能 |
| **並行開発** | ロジック担当とUI担当が独立して開発できる |
| **エンジン移植** | 将来的に Pyxel 以外のエンジンに移植する場合、`core/` はそのまま再利用可能 |

### ビューインターフェース

描画層は共通のインターフェースに従い、差し替え可能にする。

```python
from abc import ABC, abstractmethod

class BoardViewBase(ABC):
    """ボード描画の基底クラス。ビュー実装はこれを継承する。"""

    def __init__(self, board_model):
        self.board_model = board_model

    @abstractmethod
    def draw_board(self):
        """ボード全体を描画する"""
        pass

    @abstractmethod
    def draw_tile(self, tile):
        """個別のマスを描画する"""
        pass

    @abstractmethod
    def tile_screen_pos(self, tile_id: int) -> tuple[int, int]:
        """タイルIDから画面上の描画座標を返す。
        トップビューとアイソメトリックで座標変換ロジックが異なる。
        """
        pass

class PlayerViewBase(ABC):
    """プレイヤー描画の基底クラス"""

    @abstractmethod
    def draw_player(self, player, screen_x: int, screen_y: int):
        """プレイヤーを指定座標に描画する"""
        pass

    @abstractmethod
    def draw_move_animation(self, player, from_pos, to_pos, progress: float):
        """移動アニメーションを描画する（progress: 0.0〜1.0）"""
        pass
```

**トップビュー実装の例**:

```python
# src/views/topview/board_view.py
import pyxel
from src.views.view_base import BoardViewBase

class TopViewBoardView(BoardViewBase):
    """トップビュー（真上からの2D）でボードを描画する"""

    def tile_screen_pos(self, tile_id: int) -> tuple[int, int]:
        tile = self.board_model.get_tile(tile_id)
        # トップビューではグリッド座標をそのままピクセル座標に変換
        return (tile.grid_x * TILE_SIZE, tile.grid_y * TILE_SIZE)

    def draw_board(self):
        for tile in self.board_model.tiles:
            self.draw_tile(tile)

    def draw_tile(self, tile):
        sx, sy = self.tile_screen_pos(tile.id)
        pyxel.blt(sx, sy, img=1, u=tile.sprite_u, v=tile.sprite_v,
                  w=TILE_SIZE, h=TILE_SIZE)
```

**アイソメトリック実装の例**:

```python
# src/views/isometric/board_view.py
import pyxel
from src.views.view_base import BoardViewBase

class IsometricBoardView(BoardViewBase):
    """アイソメトリック（斜め上から見た2.5D）でボードを描画する"""

    def tile_screen_pos(self, tile_id: int) -> tuple[int, int]:
        tile = self.board_model.get_tile(tile_id)
        # アイソメトリック座標変換
        iso_x = (tile.grid_x - tile.grid_y) * (TILE_WIDTH // 2) + OFFSET_X
        iso_y = (tile.grid_x + tile.grid_y) * (TILE_HEIGHT // 2) + OFFSET_Y
        return (iso_x, iso_y)

    def draw_board(self):
        # アイソメトリックでは奥から手前の順で描画（Z-order）
        sorted_tiles = sorted(self.board_model.tiles,
                              key=lambda t: t.grid_x + t.grid_y)
        for tile in sorted_tiles:
            self.draw_tile(tile)

    def draw_tile(self, tile):
        sx, sy = self.tile_screen_pos(tile.id)
        pyxel.blt(sx, sy, img=1, u=tile.sprite_u, v=tile.sprite_v,
                  w=TILE_WIDTH, h=TILE_HEIGHT)
```

### シーン管理

ゲームの各画面は「シーン」として管理し、シーンマネージャーで切り替える。
シーンは `core/` のロジックと `views/` の描画を組み合わせる **調整役** である。

```python
class SceneManager:
    def __init__(self):
        self.current_scene = None
        self.scenes = {}

    def register(self, name, scene):
        self.scenes[name] = scene

    def change_scene(self, scene_name, **kwargs):
        self.current_scene = self.scenes[scene_name]
        self.current_scene.enter(**kwargs)

    def update(self):
        self.current_scene.update()

    def draw(self):
        self.current_scene.draw()

class Scene:
    def enter(self, **kwargs):
        """シーンに入る時の初期化"""
        pass

    def update(self):
        """毎フレームの更新処理"""
        pass

    def draw(self):
        """毎フレームの描画処理"""
        pass
```

**シーンでのロジック・ビュー連携例**:

```python
class MainBoardScene(Scene):
    def __init__(self, game_state, board_view, player_view):
        # ロジック（core）
        self.game_state = game_state
        # ビュー（views）
        self.board_view = board_view
        self.player_view = player_view

    def update(self):
        # ロジック層でゲーム状態を更新
        if self.game_state.phase == GamePhase.DICE_ROLL:
            if pyxel.btnp(pyxel.KEY_SPACE):
                self.game_state.roll_dice()

        elif self.game_state.phase == GamePhase.MOVING:
            self.game_state.advance_movement()

    def draw(self):
        pyxel.cls(0)
        # ビュー層で描画（ロジック層のデータを参照して描画する）
        self.board_view.draw_board()
        for player in self.game_state.players:
            sx, sy = self.board_view.tile_screen_pos(player.position)
            self.player_view.draw_player(player, sx, sy)
```

### ゲーム状態管理

`core/` 内でゲーム全体の状態を管理する。描画への依存はない。

```python
# src/core/game_state.py
from enum import Enum
from dataclasses import dataclass, field

class GamePhase(Enum):
    TURN_START = "turn_start"           # ターン開始（イベント判定）
    PLAYER_COMMAND = "player_command"   # プレイヤーコマンド選択
    DICE_ROLL = "dice_roll"            # サイコロ
    MOVING = "moving"                  # 移動中
    BRANCH_SELECT = "branch_select"    # 分岐選択
    TILE_ACTION = "tile_action"        # マス到着処理
    MANAGEMENT = "management"          # 経営
    BATTLE = "battle"                  # 戦闘
    TURN_END = "turn_end"             # ターン終了

class GameState:
    def __init__(self):
        self.turn_number: int = 1
        self.current_player_index: int = 0
        self.players: list[Player] = []
        self.board: BoardModel = None
        self.phase: GamePhase = GamePhase.TURN_START
        self.goal_assets: int = 10000

    def current_player(self) -> "Player":
        return self.players[self.current_player_index]

    def roll_dice(self) -> int:
        """サイコロを振り、結果を返す。状態をMOVINGに遷移。"""
        import random
        result = random.randint(1, 6)
        self.current_player().remaining_moves = result
        self.phase = GamePhase.MOVING
        return result

    def check_victory(self) -> "Player | None":
        """勝利条件を判定。達成者がいればそのPlayerを返す。"""
        for player in self.players:
            if not player.is_bankrupt and player.total_assets >= self.goal_assets:
                return player
        return None
```

### データモデル

```python
# src/core/player_model.py
from dataclasses import dataclass, field

@dataclass
class PlayerStats:
    total_revenue: int = 0
    total_land_income: int = 0
    total_company_income: int = 0
    battles_won: int = 0
    battles_lost: int = 0
    tiles_moved: int = 0

@dataclass
class Player:
    id: int
    name: str
    character_id: int
    is_human: bool
    money: int = 3000
    position: int = 0              # 現在のマスID
    cards: list = field(default_factory=list)       # 最大7枚
    owned_lands: list = field(default_factory=list)  # 所有する土地のマスID
    owned_companies: list = field(default_factory=list)
    is_bankrupt: bool = False
    slow_debuff_turns: int = 0     # のんびりカード残りターン
    remaining_moves: int = 0       # 残り移動マス数
    stats: PlayerStats = field(default_factory=PlayerStats)

    @property
    def total_assets(self) -> int:
        """総資産 = 所持金 + 土地評価額 + 会社評価額"""
        land_value = sum(land.price for land in self.owned_lands)
        company_value = sum(c.evaluation for c in self.owned_companies)
        return self.money + land_value + company_value
```

```python
# src/core/company_model.py
from dataclasses import dataclass

@dataclass
class Company:
    name: str
    company_type: str
    owner_id: int
    tile_id: int
    employees: int
    ability: int = 50      # 能力（0-100）
    fame: int = 50         # 知名度（0-100）
    construction_cost: int = 0
    base_revenue: int = 0  # 初期固定売上

    @property
    def fixed_revenue(self) -> int:
        return (self.fame + self.ability) // 10 + self.employees // 10

    @property
    def evaluation(self) -> int:
        return self.construction_cost + (self.fixed_revenue * 5)
```

```python
# src/core/board_model.py
from dataclasses import dataclass, field

@dataclass
class Tile:
    id: int
    tile_type: str         # normal, card_shop, plus, minus, card
    name: str
    next_tiles: list[int]  # 次のマスID（分岐対応）
    grid_x: int = 0        # グリッド上の論理座標
    grid_y: int = 0
    land_price: int = 0
    land_owner_id: int = None
    company: "Company" = None
    plus_minus_amount: int = 0

class BoardModel:
    """ボードの論理構造を管理する。描画には関与しない。"""

    def __init__(self, tiles: list[Tile]):
        self.tiles = tiles
        self._tile_map = {t.id: t for t in tiles}

    def get_tile(self, tile_id: int) -> Tile:
        return self._tile_map[tile_id]

    def get_next_tiles(self, tile_id: int) -> list[int]:
        """指定マスから進める次のマスIDリストを返す"""
        return self.get_tile(tile_id).next_tiles

    def has_branch(self, tile_id: int) -> bool:
        """分岐があるか判定"""
        return len(self.get_next_tiles(tile_id)) > 1
```

## Web実行（Pyxel Web）

### 概要

Pyxel Webを利用して、ブラウザ上でインストール不要でゲームをプレイできる。PC・スマートフォン・タブレットに対応。

### 仕組み

1. `src/` ディレクトリを `pyxel package` コマンドで `.pyxapp` ファイルにパッケージング
2. `.pyxapp` をリポジトリの `dist/` に配置
3. Pyxel Web Launcher の `play` コマンドで GitHub 上の `.pyxapp` を直接実行

### ビルド手順

```bash
# src/ をパッケージング（エントリーポイント: src/main.py）
pyxel package src src/main.py

# dist/ にコピー
mkdir -p dist
cp src.pyxapp dist/board_company.pyxapp
```

### Web実行時の制約

| 項目 | 制約 |
|---|---|
| ファイルI/O | ローカルファイルへの書き込み不可（セーブ機能はLocalStorage等で代替が必要） |
| パッケージ | Pyodide対応パッケージのみ使用可能 |
| パフォーマンス | 複数ファイルを `run` で直接実行すると遅いため `.pyxapp` 化が必須 |

### セーブ機能のWeb対応

Web実行時はファイルシステムが使えないため、セーブ/ロードの実装は環境に応じて切り替える。

```python
# src/utils/save_manager.py
import os

def is_web_environment() -> bool:
    """Pyxel Web（Pyodide）環境かどうかを判定"""
    try:
        import js  # Pyodide環境ではjsモジュールが存在する
        return True
    except ImportError:
        return False

class SaveManager:
    def save(self, data: dict):
        if is_web_environment():
            self._save_web(data)
        else:
            self._save_local(data)

    def _save_local(self, data: dict):
        """ローカル環境: JSONファイルに保存"""
        import json
        os.makedirs("saves", exist_ok=True)
        with open("saves/autosave.json", "w") as f:
            json.dump(data, f)

    def _save_web(self, data: dict):
        """Web環境: LocalStorageに保存"""
        import json
        from js import localStorage
        localStorage.setItem("board_company_save", json.dumps(data))
```
