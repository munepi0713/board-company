## アーキテクチャ

### シーン管理

ゲームの各画面は「シーン」として管理し、シーンマネージャーで切り替える。

```python
class SceneManager:
    def __init__(self):
        self.current_scene = None
        self.scenes = {}

    def change_scene(self, scene_name, **kwargs):
        self.current_scene = self.scenes[scene_name]
        self.current_scene.enter(**kwargs)

    def update(self):
        self.current_scene.update()

    def draw(self):
        self.current_scene.draw()

class Scene:
    def enter(self, **kwargs):
        """シーンに入る時の初期化"""
        pass

    def update(self):
        """毎フレームの更新処理"""
        pass

    def draw(self):
        """毎フレームの描画処理"""
        pass
```

### ゲーム状態管理

```python
class GameState:
    def __init__(self):
        self.turn_number: int = 1
        self.current_player_index: int = 0
        self.players: list[Player] = []
        self.board: Board = None
        self.phase: GamePhase = GamePhase.TURN_START

class GamePhase(Enum):
    TURN_START = "turn_start"           # ターン開始（イベント判定）
    PLAYER_COMMAND = "player_command"   # プレイヤーコマンド選択
    DICE_ROLL = "dice_roll"            # サイコロ
    MOVING = "moving"                  # 移動中
    BRANCH_SELECT = "branch_select"    # 分岐選択
    TILE_ACTION = "tile_action"        # マス到着処理
    MANAGEMENT = "management"          # 経営
    BATTLE = "battle"                  # 戦闘
    TURN_END = "turn_end"             # ターン終了
```

### メインループ

```python
import pyxel

class App:
    def __init__(self):
        pyxel.init(256, 256, title="BOARD COMPANY", fps=30)
        pyxel.load("assets/board_company.pyxres")

        self.scene_manager = SceneManager()
        # シーン登録
        self.scene_manager.register("title", TitleScene())
        self.scene_manager.register("setup", SetupScene())
        self.scene_manager.register("main", MainBoardScene())
        self.scene_manager.register("management", ManagementScene())
        self.scene_manager.register("battle", BattleScene())
        self.scene_manager.register("news", NewsScene())
        self.scene_manager.register("ending", EndingScene())

        self.scene_manager.change_scene("title")
        pyxel.run(self.update, self.draw)

    def update(self):
        self.scene_manager.update()

    def draw(self):
        self.scene_manager.draw()
```

### データモデル

```python
@dataclass
class Player:
    id: int
    name: str
    character_id: int
    is_human: bool
    money: int = 3000
    position: int = 0  # 現在のマスID
    cards: list = field(default_factory=list)  # 最大7枚
    owned_lands: list = field(default_factory=list)  # 所有する土地のマスID
    owned_companies: list = field(default_factory=list)  # 所有する会社
    is_bankrupt: bool = False
    slow_debuff_turns: int = 0  # のんびりカード残りターン
    # 統計データ
    stats: PlayerStats = field(default_factory=PlayerStats)

@dataclass
class PlayerStats:
    total_revenue: int = 0
    total_land_income: int = 0
    total_company_income: int = 0
    battles_won: int = 0
    battles_lost: int = 0
    tiles_moved: int = 0

@dataclass
class Company:
    name: str
    company_type: str
    owner_id: int
    tile_id: int
    employees: int
    ability: int = 50      # 能力（0-100）
    fame: int = 50         # 知名度（0-100）
    construction_cost: int = 0
    base_revenue: int = 0  # 初期固定売上

    @property
    def fixed_revenue(self) -> int:
        return (self.fame + self.ability) // 10 + self.employees // 10

    @property
    def evaluation(self) -> int:
        return self.construction_cost + (self.fixed_revenue * 5)

@dataclass
class Tile:
    id: int
    tile_type: str  # normal, card_shop, plus, minus, card
    name: str
    next_tiles: list[int]
    position: tuple[int, int]
    land_price: int = 0
    land_owner_id: int = None
    company: Company = None
    plus_minus_amount: int = 0  # プラス/マイナスマスの金額
```

### サウンド

Pyxelの内蔵サウンドエディタで作成：

| チャンネル | 用途 |
|---|---|
| サウンド0〜7 | 効果音（ボタンクリック、足音、支払い等） |
| サウンド8〜15 | 効果音（戦闘、カード等） |
| ミュージック0 | メインBGM |
| ミュージック1 | セットアップBGM |
| ミュージック2 | 経営画面BGM |
| ミュージック3 | 戦闘BGM |
| ミュージック4 | ニュースBGM |
| ミュージック5 | エンディングBGM |

### 効果音一覧

| ID | 効果音 | タイミング |
|---|---|---|
| 0 | ボタンクリック音 | UI操作時 |
| 1 | ダイアログ閉じ音 | Enterでダイアログを閉じた時 |
| 2 | 購入音 | 土地・会社を購入した時 |
| 3 | 足音 | マスを進む時（1マスごと） |
| 4 | 支払い音 | 使用料を支払った時 |
| 5 | 買収音 | 会社を買収した時 |
| 6 | 攻撃音 | 戦闘で攻撃した時 |
| 7 | 勝利音 | 戦闘に勝利した時 |
| 8 | 敗北音 | 戦闘に敗北した時 |
| 9 | カード使用音 | カードを使った時 |
