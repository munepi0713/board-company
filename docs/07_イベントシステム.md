# 07. イベントシステム

## イベントの発生タイミング

- 各ターンの開始時にイベント判定を行う
- 各イベントは独立した確率で発生判定される
- 複数イベントが同時に発生することもある

## 定期ニュース（BOARD NEWS）

- **5ターンごと**に必ずニュースが放送される
- イベントがなくても架空のニュースが流れる
- ニュースの結果として売上に影響が出ることがある

### ニュース演出

1. ニューススタジオの背景画像を表示
2. ニュースキャスター（男性・スーツ姿）を表示
3. キャスターが口パク演出をしながらテキストを表示
   - 口パクは単純なアニメーション（口の開閉を繰り返し）
   - テキストは一定間隔で1文字ずつ表示
4. ニュース内容の表示後、「ニュースをお伝えしました」で締め

### スポンサーシステム

ニュースにはスポンサーが付く：

1. ニュース開始前にスポンサーを2社決定（プレイヤーの所有会社からランダム選択）
2. 「提供: ○○、○○」を表示
3. ニュース終了後、スポンサーのCM演出を表示
4. スポンサーが1社のみの場合、もう1社は「EXGRACE SOFT」
5. スポンサーが0社の場合、「EXGRACE SOFT」提供とし、CM演出はカット
6. 毎回のニュースでスポンサーが偏らないよう、直近のスポンサー履歴を管理する

### Pyxelでの演出

- ニューススタジオ: 16×16タイルで構成した背景
- キャスター: 8×16のスプライト（口開き/口閉じの2フレーム）
- テキスト: Pyxel の `pyxel.text()` で表示（日本語は画像フォントで対応）

## イベント一覧

### 地価上昇

| 項目 | 値 |
|---|---|
| 発生確率 | 毎ターン 1/30 |
| 効果 | ランダムに選ばれた1つのマスの地価が **30%上昇** |
| メッセージ例 | 「○○地区の地価が上昇しました！」 |

### 地価下落

| 項目 | 値 |
|---|---|
| 発生確率 | 毎ターン 1/50 |
| 効果 | ランダムに選ばれた1つのマスの地価が **20%下落** |
| メッセージ例 | 「○○地区の地価が下落しました...」 |

### 不景気の影響

| 項目 | 値 |
|---|---|
| 発生確率 | 毎ターン 1/50 |
| 効果 | ランダムに選ばれた会社の社員が **0〜3人減少** |
| メッセージ例 | 「不景気の影響で○○社の社員が退職しました」 |

| 項目 | 値 |
|---|---|
| 発生確率 | 毎ターン 1/50 |

| メッセージ例 | 「好景気の影響で各社の売上が伸びています！」 |

### 台風情報

| 項目 | 値 |
|---|---|

| メッセージ例 | 「台風の影響で各社の事業に大きな影響が出ています！」 |

## イベントデータ構造

```json
{
  "id": "land_price_up",
  "name": "地価上昇",
  "probability": {"numerator": 1, "denominator": 30},
  "effect": {
    "type": "land_price_change",
    "target": "random_tile",
    "change_percent": 30
  },
  "message": "{tile_name}地区の地価が上昇しました！"
}
```

## イベント判定の実装

```python
import random

def check_events(turn_number, event_list):
    triggered_events = []
    for event in event_list:
        prob = event["probability"]
        if random.randint(1, prob["denominator"]) <= prob["numerator"]:
            triggered_events.append(event)
    return triggered_events

def check_news(turn_number):
    return turn_number % 5 == 0
```
