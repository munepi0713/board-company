### 依存関係ルール

- `core/` → 標準ライブラリのみ（Pyxel非依存、単体テスト可能）
- `scenes/` → `core/` + `views/` + `ui/` + `utils/`
- `views/` → `core/`（データモデル参照） + Pyxel
- `ui/` → `core/rules`（定数参照） + Pyxel
- `utils/` → `core/`（データモデル参照） + 標準ライブラリ

### 外部依存

| パッケージ | バージョン | 用途 |
|---|---|---|
| pyxel | >= 2.0 | レトロゲームエンジン |
| pyxel-mcp | (開発時) | AI開発支援 MCPサーバー |

## データファイル詳細

### map_default.json
- 40タイル: normal(25), card_shop(5), card(5), plus(3), minus(2)
- 土地価格: 100〜500$
- 分岐ポイント: 5箇所

### companies.json
- 18社: 飲食店(100$)〜航空会社(2000$)
- フィールド: type_id, name, construction_cost, initial_employees, initial_revenue

### characters.json
- 10キャラクター: 各7種のAIパラメータ
- パラメータ: aggression, investment_tendency, card_usage, flee_tendency,
  preferred_company_cost(min/max), education_priority, advertising_priority

## MCP サーバー設定

`.mcp.json` に pyxel-mcp の設定を記載。Claude Code 等のAIツールが自動検出し、
ゲームの実行・スクリーンショット撮影・デバッグを自律的に行える。

```json
{
  "mcpServers": {
    "pyxel-mcp": {
      "command": "pyxel-mcp",
      "type": "stdio"
    }
  }
}
```

### pyxel-mcp 利用可能ツール

| カテゴリ | 機能 |
|---|---|
| Run & Capture | スクリプト実行+スクリーンショット、フレーム撮影、入力シミュレーション |
| Inspect & Debug | 構文検証、ゲーム状態取得、画面比較、カラーグリッド出力 |
| Visual Analysis | スプライト、画面レイアウト、カラーパレット、タイルマップ検査 |
| Audio & Utility | サウンド/音楽のWAV出力、Pyxel情報取得 |

## 自動テスト

`tests/test_screens.py` — pyxel-mcp を使った画面遷移テスト。

```bash
# テスト実行（pyxel, pyxel-mcp が必要）
pip install pyxel pyxel-mcp
python tests/test_screens.py
```

5つのテストケースで以下を検証:
1. タイトル画面の描画
2. セットアップ画面への遷移
3. メインボード画面への遷移
4. サイコロ演出の表示
5. 数ターンのゲーム進行

スクリーンショットは `screenshots/` に自動保存される。
