# 09. UI画面設計（Pyxel向け）

## 画面解像度

- **256×256 ピクセル**（Pyxel デフォルト）
- 16色パレット
- 30 FPS

## 画面遷移

```

  │
  ├─ ゲームセットアップ画面
  │    ├─ プレイヤー人数選択
  │    ├─ キャラクター選択
  │    └─ ゲーム開始
  │
  ├─ セーブデータロード
  │
  └─ ゲームメイン画面
       │
       ├─ ボード表示 + プレイヤー情報
       ├─ サイコロ演出
       ├─ 移動アニメーション
       │
       ├─ マス到着処理画面
       │    ├─ 土地購入確認
       │    ├─ 会社建設選択
       │    ├─ 使用料支払い表示
       │    ├─ カード売買画面
       │    └─ プラス/マイナスマス演出
       │
       ├─ 経営画面
       │    ├─ 会社パラメータ表示
       │    └─ 経営コマンド選択
       │
       ├─ 戦闘画面
       │    ├─ 戦闘パラメータ表示
       │    ├─ コマンド選択
       │    └─ 攻撃/防御演出
       │

       │    ├─ スポンサー表示

       │
       ├─ データ確認画面
       │
       └─ エンディング画面
            └─ 成績表示
```

## ダイアログシステム

- 全てのゲームメッセージは**独立したダイアログ**で表示
- Enter（Return）キーまたはZキーで閉じる
- ダイアログは画面下部にオーバーレイ表示

```
┌──────────────────────────────┐
│  メッセージテキスト             │
│                   [Enter]      │
└──────────────────────────────┘
```

## ボタン表記規則

| アクション | 表記 |
|---|---|
| 同意する | [O.K.] |
| 取り消す | [Cancel] |
| 次へ進む | [Next>>] |
| 前へ戻る | [<<Back] |

## 操作体系

| キー | 機能 |
|---|---|
| 方向キー（上下左右） | カーソル移動・選択 |
| Zキー / Enter | 決定 |
| Xキー / Esc | キャンセル・戻る |
| Spaceキー | サイコロを振る |

## Pyxelフォントについて

- Pyxel 組み込みフォント（4×6px）を使用
