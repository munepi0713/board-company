# 99. 未解決事項・要確認事項（GitHub Issue化推奨）

原文仕様書（Release3）を精査した結果、以下の不明点・曖昧な点が発見されました。
各項目はGitHub Issueとして起票し、仕様確定後に各ドキュメントを更新してください。

---

## Issue #1: 固定売上の計算式が不明確

**ラベル**: `仕様確認`, `優先度:高`

原文（ページ3）の固定売上の計算式が以下のように記載されている：

```
固定売り上げ＝（知名度＋能力）＋社員数÷10 − 社員数
               10           10
```

社員数に関する項（`+社員数/10` と `-社員数/10`）が相殺されてしまい、社員数が売上に影響しない計算になる。これは意図的なものか、OCR等の読み取りミスか確認が必要。

**暫定対応**: `固定売上 = (知名度 + 能力) / 10 + 社員数 / 10` として実装する。

## Issue #2: 戦闘のダメージ計算式が不明確

**ラベル**: `仕様確認`, `優先度:高`

原文（ページ2）の戦闘公式テーブルが壊れており、正確なダメージ計算式が読み取れない。

記載内容：
```
ダメージ＝攻撃力×すばやさ | 防御力×すばやさ
・社員数、攻撃力・会社評価額
・能力、防御力 | 10 | 5
・知名度、すばやさ
逃げれる確立＝能力＋すばやさ / 300
```

**確認事項**:
1. ダメージ計算で「10」「5」「300」はどこに適用される定数か
2. 攻撃力 = 社員数 + 会社評価額 の正確な計算式（除算の分母は何か）
3. 防御力 = 能力 の正確な対応関係と倍率

**暫定対応**: `ダメージ = (攻撃力 × すばやさ / 100) - (相手防御力 × 相手すばやさ / 100)` として実装する。
