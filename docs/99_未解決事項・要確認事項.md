# 99. 未解決事項・要確認事項（GitHub Issue化推奨）

原文仕様書（Release3）を精査した結果、以下の不明点・曖昧な点が発見されました。
各項目はGitHub Issueとして起票し、仕様確定後に各ドキュメントを更新してください。

## Issue #1: 固定売上の計算式が不明確

**ラベル**: `仕様確認`, `優先度:高`

原文（ページ3）の固定売上の計算式が以下のように記載されている：

```
固定売り上げ＝（知名度＋能力）＋社員数÷10 − 社員数
               10           10
```

社員数に関する項（`+社員数/10` と `-社員数/10`）が相殺されてしまい、社員数が売上に影響しない計算になる。これは意図的なものか、OCR等の読み取りミスか確認が必要。

**暫定対応**: `固定売上 = (知名度 + 能力) / 10 + 社員数 / 10` として実装する。

## Issue #2: 戦闘のダメージ計算式が不明確

**ラベル**: `仕様確認`, `優先度:高`

原文（ページ2）の戦闘公式テーブルが壊れており、正確なダメージ計算式が読み取れない。

記載内容：
```
ダメージ＝攻撃力×すばやさ | 防御力×すばやさ
・社員数、攻撃力・会社評価額
・能力、防御力 | 10 | 5
・知名度、すばやさ
逃げれる確立＝能力＋すばやさ / 300
```

**確認事項**:
1. ダメージ計算で「10」「5」「300」はどこに適用される定数か
2. 攻撃力 = 社員数 + 会社評価額 の正確な計算式（除算の分母は何か）
3. 防御力 = 能力 の正確な対応関係と倍率

**暫定対応**: `ダメージ = (攻撃力 × すばやさ / 100) - (相手防御力 × 相手すばやさ / 100)` として実装する。

## Issue #13: 「10分で遊べる」コンセプトに対してゲーム終了条件が不適切

**ラベル**: `コンセプト整合`, `優先度:高`

コンセプトは「10分のスキマ時間に遊べるいただきストリート」であるが、現在の終了条件は「全プレイヤーの破産」のみであり、1ゲームが10分で収まる保証がない。いただきストリートでは「目標総資産額の達成」が終了条件であり、ゲーム時間のコントロールが可能である。

**改善案**:
1. いたストと同様に「目標総資産額」を勝利条件として導入する（例: 総資産 10000$ で勝利）
2. ターン数上限を設定する（例: 20ターン。上限到達時は総資産最多プレイヤーの勝利）
3. 目標額とターン上限は難易度設定やマップごとに調整可能にする
4. 破産は即脱落として残すが、メインの勝利条件は目標総資産額とする

## Issue #14: 戦闘システムが重すぎてスキマ時間向けでない

**ラベル**: `コンセプト整合`, `優先度:高`

現在の戦闘システムはHP・攻撃力・防御力・素早さを持つRPG的な戦闘であり、複数ターンの応酬が発生する。10分で1ゲームを完結させるコンセプトにおいて、毎回の戦闘が大きなボトルネックになる。

**改善案**:
1. 戦闘を「1ターンの自動判定」に簡略化する（攻撃側/防御側の総合力比較＋乱数で勝敗決定）
2. 戦闘をカードやダイスによる簡易比較に変更する（例: サイコロ＋会社能力値で一発勝負）
3. 現行の本格戦闘は「ボスバトル」等の特別なイベントのみに限定する
4. 戦闘自体をオプション化し、メインの競争は経済的手段（株・買収）で行う

## Issue #15: ボードサイズとゲームテンポの最適化が必要

**ラベル**: `コンセプト整合`, `優先度:中`

現在のボードは32マス＋8マス分岐で合計約40マス。サイコロ1個（1-6）で全マスを一周するのに平均約11ターンかかる。10分のゲームでは各プレイヤーの行動回数が限られるため、十分なゲーム体験を提供できるか懸念がある。

**改善案**:
1. マス数を16〜20マス程度に削減し、3〜5ターンで一周できる設計にする
2. いたストのように「一周ボーナス」を導入し、周回のインセンティブを作る
3. サイコロ2個にして移動速度を上げ、マス間のインタラクション頻度を高める
4. マップサイズを複数用意し、「クイックモード（小マップ・10分）」「スタンダードモード（大マップ・30分）」を選択可能にする

## Issue #16: 経済バランスが10分ゲームに対して緩やか

**ラベル**: `コンセプト整合`, `優先度:中`

初期所持金3000$に対し、会社建設費は100〜2000$、土地購入費は100〜500$。偶数ターンのみ収益計上で、能力値は毎偶数ターン-2ずつ減衰する。この経済ペースでは10分以内に決着がつきにくい。

**改善案**:
1. 初期所持金を減額する（例: 1500$）、あるいは会社の収益を増額してゲーム展開を速める
2. 毎ターン収益計上に変更する（偶数ターン限定を廃止）
3. 他プレイヤーの会社に止まった際の支払い（会社使用料+地代）を増額し、資金の流動性を高める
4. いたストの「株」に相当する間接投資手段を導入し、直接経営以外の資産増加手段を設ける

---

## Issue #17: 会社経営コマンドの意思決定コストが高い

**ラベル**: `コンセプト整合`, `優先度:中`

自社マスに止まるたびに5種類の経営コマンド（社員教育・宣伝・雇用・解雇・精算）から選択する必要がある。10分ゲームではプレイヤーのターンあたり判断時間を極力短くする必要がある。

**改善案**:
1. 経営コマンドを「投資」（能力値上昇）と「精算」（会社売却）の2択に簡略化する
2. 投資額を任意設定にし、投資額に応じて能力・知名度・社員数がバランスよく上昇する仕組みにする
3. いたストの「増資」のように、止まらなくても任意タイミングで投資可能にする
4. CPU側は自動判定にし、人間プレイヤーにもワンタップ推奨アクションを提示する

## Issue #18: ニュース演出がゲームテンポを阻害する可能性

**ラベル**: `コンセプト整合`, `優先度:低`

5ターンごとにBOARD NEWSの演出（スタジオ背景、口パクアニメ、1文字ずつ表示、スポンサーCM）が発生する。20ターン制なら4回のニュース演出が入ることになり、演出時間がゲーム時間を圧迫する。

**改善案**:
1. ニュース演出をスキップ可能にする（ボタン1つで結果のみ表示）
2. ニュース頻度を下げる（10ターンごと等）
3. ニュースをテロップ形式（画面上部に1行表示）に簡略化し、ゲーム進行を止めない
4. 演出の長さは設定で「じっくり/さくさく」を選択可能にする
