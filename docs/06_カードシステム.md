# 06. カードシステム

## 基本ルール

- カードは最大 **7枚** まで所持可能
- カードは「**通常使用**」と「**戦闘時使用**」に分類される
- 通常使用カードは、自分のターン開始時にサイコロの代わりに使用
- 戦闘時使用カードは、戦闘中の自分の戦闘ターンに使用
- カードの入手方法:
  - **カード売り場**のマスで購入
  - **カードマス**に止まると1枚ランダムで入手

## カード売り場

- カード売り場マスに止まると売買画面が開く
- **購入**: 各カードの定価で購入
- **売却**: 手持ちカードを定価の **1/5** で売却
- 販売カードのラインナップは毎回ランダムに決定（3〜5枚を表示）

  "type": "normal",

  }
}
