# 03. ターン進行・プレイヤーアクション

## ターンの全体フロー

```
ターン開始
  │
  ├─ 1. オートセーブ
  ├─ 2. イベント判定（毎ターン確率で発生）
  ├─ 3. ニュース判定（5ターンごとに必ず発生）
  ├─ 4. 偶数ターン判定 → 会社損益計上・土地使用料精算
  ├─ ★ 勝利判定（目標総資産額に到達したプレイヤーがいれば即終了）
  │
  ├─ 各プレイヤーの行動（順番に）
  │    ├─ プレイヤーコマンド選択
  │    │    ├─「サイコロ」→ サイコロを振って移動
  │    │    ├─「データ」→ 自分のデータを確認（ターン消費なし）
  │    │    └─「カード」→ カードを1枚使用（移動の代わり）
  │    │
  │    ├─ 移動処理
  │    │    ├─ 分岐選択（分岐マスの場合）
  │    │    └─ 停止確認
  │    │
  │    ├─ マス到着処理
  │    │    ├─ マスの種類に応じた処理
  │    │    └─ 戦闘判定（他プレイヤーの会社がある場合）
  │    │
  │    └─ ★ 勝利判定（資産変動後に目標到達していれば即終了）
  │
  └─ 全プレイヤーの行動完了 → 次のターンへ
```

## プレイヤーコマンド

ターン開始時にプレイヤーが選択できるコマンド：

### 1. サイコロ

- サイコロ（1〜6）を振り、出た目の数だけ自動的に進む
- 分岐がある場合は方向を選択
- 移動完了後、止まったマスの処理を実行

### 2. データ

- 自分の所有データを確認する（ターンを消費しない）
- 表示内容：
  - 所持金
  - 所有する土地一覧と各地価・土地使用料
  - 所有する会社一覧と各パラメータ（固定売上含む）
  - 所有するカード一覧

### 3. カード

- 手持ちのカード（通常使用カード）を1枚使う
- カード使用はサイコロの代わり（そのターンはサイコロを振れない）
- 使用可能なカードは「通常使用」に分類されるもののみ

## 移動処理の詳細

### サイコロ

- 1個のサイコロ（1〜6）を振る
- 出た目の数だけ、マスを1つずつ自動的に進む
- 移動中の各マスでは効果は発生しない（止まったマスのみ）

### 分岐処理

1. 分岐マスに到達時、選択肢を表示（「ルートA」「ルートB」）
2. プレイヤーが方向を選択
3. 残りの歩数分を選んだ方向に進む
4. 最終マスで「止まりますか？」を表示
   - 「はい」→ そのマスで停止、マス処理へ
   - 「いいえ」→ 分岐前の状態に戻し、別方向を選択

### のんびりカード効果中

- 対象プレイヤーは5ターンの間、1歩ずつしか進めない
- カードも使用不可

## マス到着時の処理

### 通常マスでの処理分岐

到着した通常マスの状態に応じて処理が分岐する：

#### I. 空き地（所有者なし・会社なし）

```
空き地に到着
  └─ 「この土地を購入しますか？」
       ├─ はい → 地価分の所持金を支払い、土地を取得
       │         └─ 「会社を建設しますか？」
       │              ├─ はい → 会社の種類を選択し建設
       │              └─ いいえ → ターン終了
       └─ いいえ → ターン終了
```

#### II. 他人の土地 + 他人の会社

```
他人の土地+会社に到着
  ├─ 1. 会社使用料（会社売上の30%）を会社オーナーに支払う
  ├─ 2. 土地使用料（地価の20%）を土地の地主に支払う
  ├─ 3. 戦闘が発生する（→ 05_戦闘システム参照）
  │
  └─ 追加選択肢（条件付き）
       ├─ 地価×5 の所持金がある場合 →「土地を買い取りますか？」
       │    └─ 地価×5 を地主に支払い、土地を取得
       └─ 会社評価額×4 の所持金がある場合 →「会社を買収しますか？」
            └─ 会社評価額×4 をオーナーに支払い、会社を取得
```

#### III. 他人の土地 + 自分の会社

```
他人の土地+自分の会社に到着
  ├─ 1. 土地使用料（地価の20%）を土地の地主に支払う
  └─ 2. 自分の会社の経営が可能（→ 04_会社経営システム参照）
```

#### IV. 自分の土地 + 他人の会社

```
自分の土地+他人の会社に到着
  ├─ 1. 会社使用料（会社売上の30%）を受け取る
  └─ 2. 会社評価額×4 の所持金がある場合 →「会社を買収しますか？」
       └─ 会社評価額×4 をオーナーに支払い、会社を取得
```

#### V. 自分の土地 + 自分の会社

```
自分の土地+自分の会社に到着
  └─ 自分の会社の経営が可能（→ 04_会社経営システム参照）
```

#### VI. 自分の土地 + 会社なし

```
自分の土地+会社なしに到着
  └─ 「会社を建設しますか？」
       ├─ はい → 会社の種類を選択し建設
       └─ いいえ → ターン終了
```

### 特殊マスでの処理

| マスの種類 | 処理 |
|---|---|
| カード売り場 | カードの売買画面を表示 |
| プラスマス | 指定金額を受け取る |
| マイナスマス | 指定金額を支払う |
| カードマス | ランダムにカード1枚を取得（上限7枚まで） |

## 偶数ターンの損益計上

偶数ターンの開始時に、全プレイヤーについて以下を処理：

1. **固定売上の計上**: 所有する全会社の固定売上合計を所持金に加算
2. **能力の減衰**: 所有する全会社の能力が 2 減少（下限0）
3. **知名度の減衰**: 所有する全会社の知名度が 2 減少（下限0）
4. **固定売上の再計算**: 減衰後のパラメータで固定売上を再計算
5. **土地使用料の精算**: 他人の土地上にある自分の会社から土地使用料を地主に支払う

## 破産処理

所持金が不足した場合の処理：

1. 支払い額が所持金を超過
2. 「資産を売却してください」メッセージを表示
3. プレイヤーは所有する土地・会社を選択して売却可能
   - 会社の売却額: **会社評価額の 1/2**
   - 土地の売却額: **地価の 1/2**
4. 売却しても支払い不能の場合 → **破産**
5. 破産プレイヤーの全資産（土地・会社）は無所有に戻る
6. 残り1人になった場合 → **ゲーム終了**

## 勝利判定

プレイヤーの総資産が目標総資産額（デフォルト: 10000$）に到達した時点で、即座にゲーム終了となる。

### 判定タイミング

資産が変動する以下のタイミングで判定を行う：

1. **偶数ターンの損益計上後** — 会社の固定売上加算、土地使用料精算の後
2. **マス到着処理後** — 使用料の受取・支払い、土地購入、会社建設・買収の後
3. **戦闘終了後** — 会社の獲得・喪失による資産変動の後
4. **カード使用後** — カード効果による資産変動の後

### 判定ロジック

```
総資産 = 所持金 + Σ(所有土地の地価) + Σ(所有会社の会社評価額)

if 総資産 >= 目標総資産額:
    → そのプレイヤーの勝利でゲーム終了
```

- 同一タイミングで複数プレイヤーが目標に到達した場合、総資産が多い方が勝利
- 総資産が同額の場合、所持金が多い方が勝利

## 交渉システム

- 他プレイヤーの土地に止まった際、交渉が可能（1ターンに1回）
- 交渉内容: 土地の地主に金額を提示し、その土地に自分の会社を建設させてもらう
- 交渉の成否はCPUの場合AIが判断、人間同士の場合は相手プレイヤーが選択
