# 08. キャラクターデータ

## 概要

- ゲームには10体のCPUキャラクターが用意されている
- 人間プレイヤーはキャラクターの中からコマ（グラフィック）を選択する
- 選ばれなかったキャラクターはCPUプレイヤーとして自動的に割り当てられる
- 各キャラクターは異なるAI特性（経営方針・戦闘スタイル）を持つ

## AI特性パラメータ

各キャラクターのAI行動は以下のパラメータで制御する：

```json
{
  "id": 1,
  "name": "カナダ出身の青年",
  "ai_params": {
    "aggression": 50,
    "investment_tendency": 50,
    "card_usage": 50,
    "flee_tendency": 30,
    "preferred_company_cost": {"min": 300, "max": 1500},
    "education_priority": 50,
    "advertising_priority": 50
  }
}
```

| パラメータ | 説明 | 範囲 |
|---|---|---|
| aggression | 戦闘での攻撃傾向 | 0〜100 |
| investment_tendency | 土地・会社購入の積極度 | 0〜100 |
| card_usage | カード使用頻度 | 0〜100 |
| flee_tendency | 戦闘での逃走傾向 | 0〜100 |
| preferred_company_cost | 好む会社の建設費範囲 | min〜max |
| education_priority | 社員教育の優先度 | 0〜100 |
| advertising_priority | 宣伝の優先度 | 0〜100 |

## スプライト仕様

### サイズ

- 各キャラクター: 8×16 ピクセル（Pyxel標準スプライト）
- 3方向（正面・横・後ろ）× 2フレーム（歩行アニメ）= 6フレーム/キャラ

### 配置（イメージバンク上）

- 10キャラクター × 6フレーム = 60スプライト
- イメージバンク0の上部に配置

### カラーパレット

Pyxelの16色パレットを使用。各キャラクターの特徴を色で区別する。
