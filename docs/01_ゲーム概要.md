# 01. ゲーム概要

## ゲームタイトル

**BOARD COMPANY（ボードカンパニー）**

会社経営ボードゲーム

## コンセプト

プレイヤーがボード上を移動しながら土地の購入・会社の建設・経営を行い、他プレイヤーと競争する会社経営シミュレーション × ボードゲーム。モノポリーをベースに、会社経営・戦闘要素・カードシステムを加えた独自のゲーム。

## 使用技術

- **言語**: Python 3.x
- **ゲームエンジン**: Pyxel（レトロゲームエンジン）
- **解像度**: 256×256 ピクセル（Pyxel デフォルト。必要に応じて拡張）
- **色数**: 16色（Pyxel パレット）
- **フレームレート**: 30 FPS

## プレイヤー人数

- 2〜4人（人間 + CPU の混成可能）
- 最低1人は人間プレイヤー
- CPU プレイヤーは10種類のキャラクターから選択

## ゲームの勝利条件

- 他の全プレイヤーを破産させたプレイヤーが勝利
- 全プレイヤーの合意によるゲーム終了時は、総資産（所持金 + 全会社評価額合計 + 全土地評価額合計）が最も多いプレイヤーが勝利

## ゲームの敗北条件

- 所持金が0以下になり、売却可能な土地・会社もない場合、そのプレイヤーは**破産**
- 破産したプレイヤーはゲームから脱落する
- 破産プレイヤーが保有していた土地・会社は無所有に戻る

## 初期設定

| 項目 | 値 |
|---|---|
| 初期所持金 | 3000$ |
| サイコロ | 1個（1〜6の目） |
| スタート地点 | 各プレイヤーごとにランダム決定 |

## ターン制の基本

- ゲームはターン制で進行する
- 各ターンで全プレイヤーが順番に行動する
- ターン開始時にイベント判定が行われる
- **偶数ターン**の開始時に、所有する全会社からの損益が計上される
- 5ターンごとに必ずニュース（BOARD NEWS）が放送される
- ターン開始時にオートセーブが実行される

## データのプラグイン構造

以下のデータは外部ファイル（JSON）で管理し、追加・変更可能とする：

1. **マップデータ** — ボードの構成・マスの配置
2. **会社データ** — 会社の種類・初期パラメータ
3. **キャラクターデータ** — CPUキャラクターの情報・AI特性
4. **イベントデータ** — ランダムイベントの内容・確率
5. **カードデータ** — カードの種類・効果・価格

## 通貨単位

- ゲーム内通貨の単位は **$**（ドル）
