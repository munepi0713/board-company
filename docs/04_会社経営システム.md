# 04. 会社経営システム

## 会社のパラメータ

各会社は以下のパラメータを持つ：

| パラメータ | 説明 | 初期値 | 範囲 |
|---|---|---|---|
| 会社名 | 会社の名前 | プレイヤーが命名 | 文字列 |
| 会社の種類 | 業種（商社、銀行など） | 建設時に選択 | 定義済みリスト |
| 社員数 | 従業員の数 | 会社種類により異なる | 0〜9999 |
| 能力 | 社員の能力値（防御力に対応） | 50 | 0〜100 |
| 知名度 | 会社の知名度（すばやさに対応） | 50 | 0〜100 |
| 固定売上 | 毎偶数ターンの収入 | 会社種類により異なる | 自動計算 |
| 建設費 | 会社の建設にかかった費用 | 会社種類により異なる | 固定 |
| 会社評価額 | 会社の現在価値 | 自動計算 | 自動計算 |
| オーナー | 会社の所有者 | 建設したプレイヤー | プレイヤーID |

### 制約

- 同じ種類の会社は、1人のプレイヤーが**1つしか経営できない**
- 買収等で同種の会社を取得した場合は **吸収合併** される（後述）

## 計算式

### 固定売上の計算

```
固定売上 = (知名度 + 能力) / 10 + 社員数 / 10 - 社員数 / 10
```

> ※ 原文仕様では上記のように定義されているが、実質的に社員数項が相殺されている。
> → Issue で確認予定。暫定的に以下の式を使用する：

```
固定売上 = (知名度 + 能力) / 10 + 社員数 / 10
```

### 会社評価額の計算

```
会社評価額 = 建設費 + (固定売上 × 5)
```

### 会社使用料（他プレイヤーが止まった時）

```
会社使用料 = 固定売上 × 30%（小数点以下切り捨て）
```

### 土地使用料

```
土地使用料 = 地価 × 20%（小数点以下切り捨て）
```

## 経営コマンド

自分の会社があるマスに止まった時に実行可能。
**1回の経営で、同じコマンドは1回しか実行できない。**

### 1. 社員教育

| 項目 | 値 |
|---|---|
| コスト | 社員数 × 15$ |
| 効果 | 能力が 20 上昇（上限100） |
| 備考 | 能力は偶数ターンに 2 ずつ自然減衰する |

### 2. 宣伝

| 項目 | 値 |
|---|---|
| コスト | 200$ |
| 効果 | 知名度が 20 上昇（上限100） |
| 備考 | 知名度は偶数ターンに 2 ずつ自然減衰する |

### 3. 採用

| 項目 | 値 |
|---|---|
| コスト | 採用人数 × 15$ |
| 効果 | 社員数が指定人数分増加 |
| 備考 | プレイヤーが採用人数を入力する |

### 4. 社員解雇

| 項目 | 値 |
|---|---|
| コスト | 0$（解雇手当なし） |
| 効果 | 社員数が指定人数分減少 |
| 備考 | 社員数減少により固定売上が再計算される |

### 5. 会社清算

| 項目 | 値 |
|---|---|
| コスト | 0$ |
| 効果 | 会社を解散し建物を撤去する |
| 備考 | 会社評価額の 1/2 を受け取る。土地との契約も解除される |

## 吸収合併

買収・競願などで既に所有している種類と同じ種類の会社を取得した場合：

1. 取得した会社の**社員数**を自社に加算
2. 取得した会社の**固定売上**を自社に加算
3. 取得した会社の**建設費の 1/2** を自社の建設費に加算
4. **能力**: 自社と取得会社の平均値
5. **知名度**: 自社と取得会社の平均値
6. 取得した会社は消滅し、そのマスの建物は撤去される

## 1マスに複数会社がある場合

マスの角や分かれ道の角など、1つのマスに2つ以上の会社が建設されている場合：

- 会社使用料は**全額**（各会社それぞれの使用料を支払う）

## 会社の撤去と土地契約

- 会社が撤去された場合、土地の地主との契約は自動的に解除される
- それまでに発生した土地使用料は受け取り済みのまま
- 再度建設する場合は改めて交渉が必要
