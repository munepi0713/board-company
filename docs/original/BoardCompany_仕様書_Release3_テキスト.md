## ページ2：ゲームの基本ルール／ゲームの流れ

この仕様書は、以下のことに基づいて作成されています。
1）ゲームに表示されるメッセージはすべて独立したダイアログに表示され、Enter（Return）キーで閉じる
2）ゲームの基本となるシステムはプラグイン構造である。したがって、マップデータ・建物（会社）データ・コンピュータキャラクタデータ・イベントデータ・カードデータを後から追加できる。

【ゲームの基本ルール】

1）ゲームはターン制で順番に行われる
2）全会社使用料は、その時点でのその会社の売り上げの30%
3）土地使用料は、地価の20%
4）ひとつのマスにある土地の所有者と会社のオーナーは別のプレーヤーであっても良い
5）仮にプレーヤーは、同じ種類の会社を1つしか経営（建設）できない

買収や競願などで既に経営していた種類と（自社であっても）同じ種類を会社を手に入れた場合、その会社の全社員数・固定売り上げ・建設費の1/2を自社に加算でき、能力・知名度は自社と自社の平均値を使う。
5）所持金がなくなる。所有する土地・会社を選択し会社評価額の1/2を売ることができる。
6）自社の所持金がなくなり売れるものもない。そのプレーヤーは破産になりゲームは終わる。
仮に破産プレーヤーがオーナーだったプレーヤー（パトロン）からはなにもかわらない。
7）ゲーム開始から数えて偶数のターンの初めに、所有する会社からの損益が計上される。
8）地主で、所有する土地の上にプレーヤーの会社が建設されている場合、その残金を確認し一番多くその土地の土地使用料料が会社オーナーから土地の地主に支払われる。

ゲーム開始時は、人間がプレーヤーの場合はコンピュータキャラクタの中からコマを選ぶ。
選んだコマのグラフィックが割り当てられていないコンピュータキャラは自動的に割り当てられる。

【ゲームの流れ】

1）サイコロを振る
（自分の目の数だけ自動的に進む）
（分かれ道がある場合、分かれた選択をする → 出た目 進んだ段で「止まりますか？」というメッセージが表示される → No を選ぶと、サイコロを振った直後の状態に戻る。
2）プレーヤーが止まったマスに止まったら（そのマスはプレーヤー3,4人にまで入れる）
3）次のプレーヤーはなるべく、自分の所有する全会社の自動につまり残りはなりたいが、相手のプレーヤーの持つ会社に止まった場合は（自社所有の全会社と）100$プレーヤーに支払う。
すばやさが低い会社にしか順ターン制にはなれない。すばやさは自分が所有する全社の、毎戦闘ターンランダムでどちらで決まる。

【戦闘コマンド】攻撃・防御・カード・逃げる
（攻撃）通常攻撃をする → 一撃で勝負
（防御）防御に力を入れる → 防御力がその戦闘ターン1ターンの間、5倍になる。
（カード）所持しているカードを使う事ができる
（逃げる）戦闘から離脱する → 逃げるの成立で、戦闘終了、相手のプレーヤーにある程度のSOSを下す

支払い

会社のパラメータは、以下の能力に相当

| 戦闘公式 |
|---|
| ダメージ＝攻撃力×すばやさ | 防御力×すばやさ |
| ・社員数、攻撃力・会社評価額 |
| ・能力、防御力 | 10 | 5 |
| ・知名度、すばやさ | | |
| 逃げれる確立＝能力＋すばやさ |
| | 300 |

負けたプレーヤーは、負けたプレーヤーの会社を手に入れる
3,4人の場合、どのような方がプレーヤーがこのさされたプレーヤーの会社のようになり

## ページ3：土地と経営

I）その土地が空き地の場合
所持金があれば、購入することができる

II）他人の土地＋他人の会社の場合
1）会社使用料と土地使用料を支払う

II）地価の5倍の所持金があり、地価の5倍の金額を土地の地主に払えば、自分の所有になる。
III）会社評価額の4倍の所持金があり、会社評価額の4倍の金額をその会社のオーナーに支払えば、自分の所有になる。

ひとつのマスにおいて、土地の地主と会社のオーナーが違う場合、会社が撤去されると自動的に地主と結んだ契約は解除になる。しかし、しかしながら、それまでの土地使用料を受け取る事はできる。再度交渉する必要がある。

マスの角や分かれ道の角の一部のように、ひとつのマスの四方に会社が2つ以上建設されている場合、会社使用料は全額

III）交渉（金額）にお金を払い、会社に土地を利用するように選ぶことも出来る。
地に会社を建設されてくれる（交渉は1ターンに1回だけ）

IV）他人の土地＋自分の会社の場合
1）土地使用料を支払う
2）自分の所有の会社をひとつ選択し、その会社の経営を行うことができる

V）自分の土地＋他人の会社
1）会社使用料を受け取る
2）会社評価額の4倍の所持金があり、会社評価額の4倍の金額をその会社のオーナーに支払えば、自分の所有の会社になる。
3）自分の所有の土地にいくつの会社が建てられていようと土地はひとつの会社になる。

VI）自分の土地＋会社なし
1）自分所有の土地に、会社が建設されていようと土地にひとつの会社を建設する。
2）自分の土地の中＋自分の会社
3）自分の所有の会社をひとつ選択し、その会社の経営を行うことができる。
