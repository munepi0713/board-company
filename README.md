# BOARD COMPANY（ボードカンパニー）

会社経営シミュレーション x ボードゲーム。Pyxelで動くレトロスタイルの対戦ゲームです。

## ゲーム概要

プレイヤーがボード上を移動しながら土地の購入・会社の建設・経営を行い、他プレイヤーと競争します。モノポリーをベースに、会社経営・戦闘・カードシステムを加えた独自のボードゲームです。

- 2〜4人対戦（人間 + CPU の混成可）
- 目標総資産 **10,000$** に最初に到達したプレイヤーの勝利
- 1ゲーム約10分のお手軽プレイ

## セットアップ

### 必要環境

- Python 3.9 以上

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/munepi0713/board-company.git
cd board-company

# 依存パッケージをインストール
pip install -r requirements.txt
```

### ゲームの起動

```bash
python -m src.main
```

## 遊び方

### 基本ルール

1. **サイコロを振って移動** — 1〜6の目が出て、その数だけマスを進みます
2. **土地を買う** — 空き地に止まったら購入できます
3. **会社を建てる** — 自分の土地に会社を建設して収益を得ます
4. **使用料を徴収/支払い** — 他プレイヤーの土地に止まると使用料が発生します
5. **目標達成で勝利** — 総資産（所持金 + 土地 + 会社）が 10,000$ に到達すれば即勝利

### ターンの流れ

```
ターン開始 → コマンド選択 → サイコロ → 移動 → マスのアクション → ターン終了
```

- **偶数ターン** に全会社から損益が計上されます
- **5ターンごと** にニュース（BOARD NEWS）が放送され、経済に影響を与えます

### コマンド一覧

| コマンド | 説明 |
|---|---|
| サイコロを振る | サイコロを振って移動する |
| カードを使う | 手持ちのカードを使用する（移動前） |
| 経営を見る | 自分の会社の状態を確認する |
| 資産を確認 | 全プレイヤーの資産状況を見る |

### マスの種類

| マス | 効果 |
|---|---|
| 通常マス | 土地の購入・会社の建設が可能 |
| カードショップ | カードを購入できる（1枚 500$） |
| プラスマス | お金がもらえる |
| マイナスマス | お金を支払う |
| カードマス | 無料でカードを1枚もらえる |

### 会社経営

自分の土地に会社を建てると、偶数ターンに収益が入ります。

- **社員の雇用** — 売上アップ（1人 100$）
- **能力の強化** — 売上 & 戦闘力アップ
- **宣伝活動** — 知名度アップで売上増加
- **会社の売却** — 建設費の50%で売却

### 戦闘システム

他プレイヤーの土地に止まった時、使用料の代わりに戦闘を挑むことができます。

- 勝利すると使用料免除 + 会社を奪取
- 敗北すると使用料に加え追加ペナルティ
- 戦闘中はカードを使って逆転も可能

### カード

全12種類のカードが存在します。フィールドで使えるカードと戦闘専用カードがあります。

## 技術構成

- **言語**: Python 3.9+
- **ゲームエンジン**: [Pyxel](https://github.com/kitao/pyxel) 2.x（レトロゲームエンジン）
- **解像度**: 256 x 256 ピクセル / 16色 / 30 FPS
- **データ**: JSON 形式（マップ・会社・キャラ・イベント・カード）

### アーキテクチャ

UI（描画）とゲームロジックを疎結合に設計しています。

```
src/
├── core/       # ゲームロジック（Pyxel非依存・テスト可能）
├── views/      # 描画層（差し替え可能：トップビュー / アイソメトリック）
├── ui/         # UI部品（ダイアログ・メニュー・HUD）
├── scenes/     # シーン管理（ロジックとビューの橋渡し）
└── utils/      # ユーティリティ
```

`core/` は Pyxel に一切依存しないため、`views/` を差し替えることでトップビューからアイソメトリック表示への変更が可能です。詳細は [docs/10_技術設計.md](docs/10_技術設計.md) を参照してください。
